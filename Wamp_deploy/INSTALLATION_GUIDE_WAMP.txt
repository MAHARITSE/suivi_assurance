========================================================================
GUIDE D'INSTALLATION ET DÉPANNAGE SUR WAMP SERVER (LOCAL)
========================================================================

1. COPIE DES FICHIERS
------------------------------------------------------------------------
Copiez le contenu du dossier "Wamp_deploy" dans le répertoire www de WAMP Server :
Exemple : C:\wamp64\www\suivi_assurance


2. IMPORTATION DE LA BASE DE DONNÉES (MySQL / phpMyAdmin)
------------------------------------------------------------------------
1. Démarrez WAMP Server et attendez que l'icône devienne VERTE.
2. Ouvrez phpMyAdmin dans votre navigateur :
   http://localhost/phpmyadmin
3. Créez une base de données nommée : suivi_assurance_salfa
4. Cliquez sur l'onglet "Importer".
5. Sélectionnez le fichier :
   C:\wamp64\www\suivi_assurance\schema.sql
6. Cliquez sur "Exécuter" en bas.


3. ACCÈS À L'APPLICATION
------------------------------------------------------------------------
Ouvrez votre navigateur et accédez impérativement avec le slash final :
http://localhost/suivi_assurance/


4. DÉPANNAGE - EN CAS DE PAGE BLANCHE
------------------------------------------------------------------------
Si vous obtenez une page blanche :

1. Assurez-vous d'utiliser l'URL avec le slash à la fin :
   -> http://localhost/suivi_assurance/ (et non http://localhost/suivi_assurance)

2. Vérifiez que MySQL est bien démarré dans WAMP Server (icône verte).

3. Assurez-vous que l'extension PDO MySQL est activée dans WAMP :
   -> Clic gauche sur l'icône WAMP -> PHP -> Extensions PHP -> pdo_mysql (doit être coché)

4. Si besoin, vous pouvez également accéder directement à :
   -> http://localhost/suivi_assurance/index.php
========================================================================
