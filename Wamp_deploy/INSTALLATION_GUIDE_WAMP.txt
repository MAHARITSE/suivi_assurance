========================================================================
GUIDE D'INSTALLATION DE L'APPLICATION SUR WAMP SERVER (LOCAL)
========================================================================

1. COPIE DES FICHIERS
------------------------------------------------------------------------
Copiez le dossier "Wamp_deploy" dans le répertoire www de WAMP Server :
Exemple : C:\wamp64\www\suivi_assurance


2. IMPORTATION DE LA BASE DE DONNEES (MySQL / phpMyAdmin)
------------------------------------------------------------------------
1. Démarrez WAMP Server et attendez que l'icône devienne VERTE.
2. Ouvrez phpMyAdmin dans votre navigateur :
   http://localhost/phpmyadmin
3. Cliquez sur l'onglet "Importer".
4. Selectionnez le fichier :
   C:\wamp64\www\suivi_assurance\schema.sql
5. Cliquez sur "Executer" en bas.


3. ACCÈS À L'APPLICATION
------------------------------------------------------------------------
Ouvrez votre navigateur et accédez à :
http://localhost/suivi_assurance/

L'application s'initialisera automatiquement et se connectera
à la base de données MySQL "suivi_assurance_salfa".
