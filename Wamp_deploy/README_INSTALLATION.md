# Instructions d'Installation WampServer

Ce package est prêt pour une exécution sur WampServer local avec PHP 7.4+ ou PHP 8.x et MySQL 5.7+ / 8.0+.

## Étapes :

1. Placer le dossier dans `C:\wamp64\www\suivi_assurance`
2. Ouvrir `http://localhost/phpmyadmin`
3. Importer `schema.sql`
4. Accéder à `http://localhost/suivi_assurance`
