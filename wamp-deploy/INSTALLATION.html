Déploiement WAMP Server en 4 Étapes Simple

Ce dossier contient le serveur backend PHP avec les scripts d'API REST, le schéma SQL de la base de données MySQL ainsi que les fichiers compilés du tableau de bord Suivi Assurance SALFA.

1

Emplacement des Fichiers dans WAMP

Copiez ce dossier dans le répertoire racine web

Copiez l'intégralité du dossier d'application dans le répertoire www de votre serveur WampServer :

C:\wamp64\www\suivi-assurance\
2

Créer la base MySQL via phpMyAdmin

Importation automatique du schéma SQL

  1. Accédez à http://localhost/phpmyadmin.
  2. Allez dans l'onglet Importer.
  3. Sélectionnez le fichier database/schema.sql.
  4. Cliquez sur Exécuter pour générer la base suivi_assurance_salfa.
3

Configuration Identifiants MySQL

Vérification dans api/config.php

Ouvrez le fichier api/config.php et adaptez les identifiants si nécessaire : 

define('DB_HOST', 'localhost');
define('DB_NAME', 'suivi_assurance_salfa');
define('DB_USER', 'root');
define('DB_PASS', ''); // Mot de passe MySQL WAMP
4

Activation du Rewrite Apache

Pour le routage des API REST

Cliquez sur l'icône WampServer > Apache > Modules Apache > cochez rewrite_module.

Redémarrez les services WAMP après l'activation.

Diagnostics & Réponses aux Erreurs

Erreur 404 lors d'un appel API (/api/societes)

Le module Apache mod_rewrite n'est pas activé ou le fichier .htaccess est ignoré par Apache.

Solution : Dans WAMP, activez "rewrite_module" et vérifiez dans httpd.conf que "AllowOverride All" est activé sur le répertoire www.

Erreur 500 "PDOException: Could not connect to server"

Le serveur MySQL n'est pas démarré ou le mot de passe dans api/config.php est incorrect.

Solution : Vérifiez que l'icône WAMP est verte et adaptez DB_PASS dans api/config.php.
