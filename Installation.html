Guide d'Installation WAMP Server - Suivi Assurance SALFA

Ce dossier contient l'application web complète configurée en client-serveur 100% MySQL pour une utilisation sur un poste unique ou en réseau multi-poste (plusieurs utilisateurs connectés à la même base de données en temps réel).

Fonctionnement 100% MySQL strict : L'application ne conserve aucun cache autonome hors-ligne. Si la base MySQL suivi_assurance_salfa est supprimée ou le serveur WAMP arrêté, l'application bloque immédiatement l'accès avec un message explicite pour garantir qu'aucune donnée divergente ne soit saisie.

1 Copier les fichiers dans WAMP Server

Copiez l'intégralité du contenu de ce dossier wamp-deploy dans votre répertoire web WAMP :

C:\wamp64\www\suivi-assurance\

(ou C:\xampp\htdocs\suivi-assurance\ si vous utilisez XAMPP)

2 Démarrer WAMP Server

Assurez-vous que l'icône WAMP dans la barre des tâches est verte (Apache et MySQL en cours d'exécution).

3 Importer la Base de Données MySQL

Pour initialiser la base de données relationnelle :

  1. Ouvrez phpMyAdmin dans votre navigateur : http://localhost/phpmyadmin
  2. Cliquez sur l'onglet Importer dans le menu supérieur.
  3. Sélectionnez le fichier schema.sql situé dans ce dossier wamp-deploy.
  4. Cliquez sur Exécuter en bas de page.
La base de données suivi_assurance_salfa sera créée avec toutes ses tables (societes, personnes, familles, prestations, paiements, lignes_prestation, lignes_paiement).

4 Configuration MySQL (config.php)

Le fichier config.php à la racine contient les paramètres de connexion :

<?php
define('DB_HOST', 'localhost');
define('DB_PORT', '3306');
define('DB_NAME', 'suivi_assurance_salfa');
define('DB_USER', 'root');
define('DB_PASS', ''); // Mot de passe vide par défaut sous WAMP

5 Utilisation en Réseau Multi-Poste (Plusieurs PC)

Pour que d'autres ordinateurs du réseau local (secrétariat, caisse, comptabilité) accèdent à la même base de données :

  1. Sur le PC Serveur WAMP, trouvez son adresse IP locale (ex: 192.168.1.50 via la commande ipconfig).
  2. Vérifiez que WAMP est configuré pour accepter les connexions du réseau local (clic gauche sur l'icône WAMP > Passer en ligne ou vérifiez que le virtual host autorise Require all granted).
  3. Sur tous les autres postes du réseau, ouvrez simplement le navigateur et saisissez l'adresse : 
    http://192.168.1.50/suivi-assurance/
  4. Synchronisation automatique : Toutes les créations, modifications ou suppressions effectuées sur un poste sont automatiquement synchronisées en temps réel sur tous les autres postes connectés.

6 Lancer l'Application sur le Poste Serveur

Ouvrez votre navigateur web et accédez à :

Ouvrir l'application (http://localhost/suivi-assurance/)
